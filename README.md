# Offlinely MVP

MVP оффлайн-векторной карты как PWA с управляемым кэшированием.

## Что есть
- PWA (`manifest.webmanifest` + `sw.js`)
- Векторная карта на MapLibre
- Поиск города/страны
- Ручная загрузка выбранной области (bbox + диапазон zoom)
- Переключатель автоскачивания при просмотре карты
- Информация по использованию/квоте хранилища

## Запуск
Нужен локальный HTTP сервер (не `file://`).

```powershell
cd d:\Offlinely
python -m http.server 8080
```

Открыть: `http://localhost:8080`

## Сценарий
1. Найти город/страну через поле поиска.
2. Задать `Min zoom` / `Max zoom`.
3. Нажать `Скачать выбранную область`.
4. Отключить интернет и открыть карту снова.

## Важно про 10 GB
- Кэш хранится в браузерном хранилище (Cache API + IndexedDB настройки).
- Реальная квота зависит от браузера, ОС, свободного места и политики хранения.
- На части устройств можно получить гигабайты, но гарантировать фиксированные `10 GB` для всех нельзя.
- В приложении есть индикатор `Использовано / Квота`, чтобы контролировать объем.

## Ограничения MVP
- Для огромных стран/больших zoom уровней число тайлов быстро растет; введен защитный лимит по количеству запросов.
- Это MVP без очереди фоновых задач и без пакетного формата регионов (например, PMTiles).
